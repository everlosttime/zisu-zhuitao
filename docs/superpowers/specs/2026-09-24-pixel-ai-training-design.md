# 像素风人机训练与词库扩充设计

## 目标

在原有像素方块城市和 HUD 面板中增加本地人机对战。玩家固定扮演警察，电脑固定扮演小偷，并提供低、中、高三档稳定速度；同时扩充中文练习词库。发布到原 GitHub Pages 地址时只发布像素风 fallback 页面，不发布旧的 2D Next 页面。

## 视觉与部署

- 保留 `fallback/src/RaceScene.tsx` 的方块城市、坐骑追逐、字幕式输入和 `cinema.css` 面板风格。
- 大厅沿用原面板，只增加“好友对战 / 人机训练”切换和三档难度选项。
- 人机对局复用相同场景、倒计时、计时器、进度和结果面板，不引入另一套页面。
- GitHub Pages 从 `gh-pages` 分支根目录提供静态文件；使用 `npm run build:fallback` 生成唯一发布入口。`app/page.tsx` 的旧 2D 页面不进入 Pages 构建产物。

## 对局规则

- 好友对战继续使用当前 MQTT over WSS 实时中继和房间流程，且大厅默认选中好友模式。
- 人机模式完全本地运行，不连接实时中继、不创建房间。玩家是警察，电脑小偷按低、中、高难度分别以每分钟 20、40、60 个正确字符前进。
- AI 进度根据比赛开始后的流逝时间计算，不依赖 interval 次数；三秒倒计时期间为零，且不超过文章长度。
- 使用现有三秒倒计时、120 秒时限、初始 20 米间距、每个正确字符改变 2 米距离，以及警察追上即获胜的规则。
- 本地训练可按当前难度重赛并轮换文章；完赛后可以返回大厅。

## 练习词库

- 导出 200 条原创短句，覆盖日常生活、自然与地理、科学与技术、文化与历史、运动与健康、出行与交通。
- 每条短句至少 18 个 Unicode 字符，只在结尾使用句号、叹号或问号。
- 使用固定种子从句库稳定生成 30 篇文章，每篇取 45 条互不重复的句子，长度不少于 800 个 Unicode 字符。
- 好友模式和人机模式共享同一篇文章；重赛遍历全部 30 篇。

## 验收标准

1. Pages 地址继续展示原方块像素场景和现有面板，且不显示旧 2D 页面。
2. 大厅默认保留好友对战；切换人机训练后可选低、中、高，玩家以警察身份进入本地比赛。
3. AI 在倒计时不前进，倒计时后稳定按 20/40/60 字每分钟前进，且文章结束时停止。
4. 人机胜负、输入、中文输入法、计时与重赛使用现有对局规则；人机对局不发送联机消息。
5. 好友实时创建、加入、同步和重赛流程继续工作。
6. 200 条句子及 30 篇文章满足数量、长度、去重和稳定轮换约束。
7. 静态构建可成功发布到 `gh-pages` 根目录，原地址的页面、脚本和样式均返回 HTTP 200。
